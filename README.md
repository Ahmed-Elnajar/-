# Advertising & Print ERP — Pilot
نظام تجريبي عربي لإدارة نشاط الدعاية والإعلان والمطبعة.

## الحالة
هذا المستودع يبدأ الآن ببنية الإصدار التجريبي. لا تستخدمه بعد لإدارة أموال حقيقية أو أرصدة افتتاحية قبل اجتياز اختبارات القبول والمراجعة المحاسبية.

## التشغيل المحلي
- Python 3.11+
- `pip install -r requirements.txt`
- `uvicorn app.main:app --host 127.0.0.1 --port 8765`
- افتح `http://127.0.0.1:8765`

## النطاق المرحلي
العملاء والموردون، أوامر الشغل، الأصناف وحركات المخزون، التحصيلات، وسجل الأحداث. سيُضاف الترحيل المحاسبي والإنتاج والتكاليف واختبارات التكامل قبل اعتبار النسخة صالحة للتشغيل الفعلي.

## الأمان
قاعدة البيانات محلية في مجلد data. لا تضع كلمات مرور أو بيانات عملاء حقيقية في المستودع. النسخة الحالية ليست متعددة المستخدمين أو خادم LAN إنتاجيًا.
